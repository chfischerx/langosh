# Code of Conduct

## Our pledge

We want Langosh to be a welcoming, respectful community for everyone
who wants to build with it — contributors, maintainers, and users of
all backgrounds and experience levels.

## Standard

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its Code of Conduct. The full text (in [many translations](https://www.contributor-covenant.org/translations))
is the authoritative source — it describes the behavior we expect,
behavior we don't, and how maintainers respond.

In short:

- Treat other people the way you'd want to be treated.
- Give and accept constructive feedback gracefully.
- Disagree technically; don't attack each other personally.
- If you see something that's off, report it (see below).

## Scope

The code of conduct applies to all project spaces — the GitHub
repository (issues, pull requests, discussions, code review
comments, commit messages), the documentation site, and any other
venue where people engage with Langosh on the project's behalf.

## Reporting

If you experience or witness behavior that violates this code,
please report it to the maintainer privately:

- **Preferred:** open a private [security advisory](https://github.com/chfischerx/langosh/security/advisories/new)
  (works for conduct reports, not only security). The form is
  private and goes to the maintainer.
- Alternatively, reach out directly via the contact details on
  [langosh.ai](https://langosh.ai).

Reports will be reviewed promptly and kept confidential. The
maintainer will respond within 7 days.

## Enforcement

Consequences follow the escalation ladder in the Contributor
Covenant's [*Community Impact Guidelines*](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction → warning → temporary ban → permanent ban. The
maintainer has final say.
